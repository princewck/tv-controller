# 电视时间

给电视安排休息时间，让家长在手机或电脑上管理观看。

电视时间是一套用于 Android TV 的家长管理工具：记录视频观看情况，在需要休息时显示学习挑战，并让家长随时调整规则或临时放行。支持多个家庭独立使用。

## 可以做什么

- **查看观看情况**：了解今天看了多久、用了哪些应用，以及最近30天的观看时段。
- **安排观看与休息**：设置观看额度、休息提醒和禁止观看的时间。
- **随时临时放行**：需要继续观看时，由家长发放指定时长。
- **选择学习内容**：按年龄分组预选数学、语文或英语题型，家长可以调整。
- **安排屏幕展示**：由 AI 助手提交展示内容，通过审核后由家长确认展示；此功能需先配置审核服务。
- **一家一套配置**：管理员创建家庭账号，各家庭独立管理自己的电视、规则和记录。

不需要更换电视桌面。完成首次安装配置后，日常通过网页管理。

## 开始使用

安装前准备 Android 8.0 及以上的电视，以及能操作终端、可访问电视网络的电脑。

**已有服务账号？** 账号由服务管理员分配，本仓库不提供公共服务或开放注册。登录服务提供者给你的管理后台，创建设备并保存安装凭证，再按[电视安装指南](docs/AI-INSTALL.md)完成配置。

**想部署自己的服务？** 按[部署与维护手册](docs/DEPLOYMENT.md)准备域名和服务器，再安装电视端。

### 让 AI 助手带你安装

将下面这句话复制给能操作电脑终端的 AI 编程助手：

```text
请阅读 https://github.com/princewck/tv-controller 的安装文档，帮我在 Android TV 上安装电视时间：先确认我使用已有服务还是自行部署，再完成检查、配置、安装和验证；保护我的凭证，保留原来的电视桌面。
```

助手会根据你的环境带你完成流程。你需要在电视上确认首次调试授权，并用遥控器配合验证。

仓库暂未提供可直接下载的 APK。已有服务的用户可向服务提供者索取匹配的安装包，否则按安装指南从源码构建。不同电视的后台限制不同，能否在关闭调试及重启后正常工作，需要在安装时验证。
