# 发布核验记录

`release-gates.json` 是尚未全部通过的发布检查表，`cloud-environment.json` 记录云端资源与部署区别，`store-metadata.zh-Hans.json` 是未提交的商店文案草案。源码中不包含签名密钥、Apple 登录凭证、设备令牌、运行数据库或真实家庭数据。

iOS 16 项、家庭云 10 项和 Android 运行时 7 项测试曾在维护者本机通过。它们不证明公网服务、真实 Apple 沙盒购买、电视播放控制或完整重启已经验收。实际测试结果包、签名 IPA、APK 及本机日志不进入 Git；正式下载通过包含版本号的 CDN 地址提供，只有公网字节、签名和 SHA-256 检查完成后才能作为安装交付。

签名发布由持有原签名证书的维护者执行。其他开发者可以构建 Debug 版本验证源码；不得修改既有版本的下载内容或用新签名覆盖用户已有的安装。已发布版本变更需要新版本号，构建后更新清单中的实际哈希并重新完成验收。
