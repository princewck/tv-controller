# 配置观有度电视端

把家长截图中的电视连接到已有家庭服务。手机只展示四步引导，所有安装与验收要求在本技能中。不要给每个家庭部署服务器，也不要用演示数据代替真实设备验收。

先读取 [安装与验收](references/install.md)，按其中的先后顺序执行。遇到型号差异时，再读 [兼容性处理](references/compatibility.md)。技能包中的 `assets/release.json` 指定此版本匹配的通用 APK、SHA-256 和签名证书指纹；不按电视型号重新编译。

输入是家长发来的安装页截图：HTTPS 服务地址、设备标识、单次安装码。电视和运行 Agent 的电脑必须在同一 Wi-Fi；电视 IP 由家长提供或从该电视的网络设置读取。安装需要家长在电视上接受调试授权。

使用 `scripts/redeem-installation.py` 兑换安装码，使用 `scripts/download-apk.py` 下载并校验固定版本的安装包，使用 `scripts/native-manage.py` 完成初始配置。详细参数和凭证处理在安装参考中。不要把家庭账号密码、设备令牌或安装凭证上传给第三方。

结束条件是手机对**本页设备**显示全部健康检查通过，并在关闭 ADB 后完成系统重启与播放控制复测。APK 安装成功、云端保存成功、出现覆盖页面或一次在线状态都不是结束条件。未通过时报告具体缺项，保留家长的系统设置与维护入口，不把结果写成已完成。
