# 学习题库与家长安排的屏幕展示

[返回首页](../README.md) · [安装与部署](DEPLOYMENT.md)

## 选择题库

在后台“学习题库”选择年龄分组和科目，点击“保存题库设置”。配置在本家庭共享，每台电视仍独立计时。

年龄分组有 4—6、7—9、10—12、13 岁及以上。“按年龄预选科目”只是快捷填入建议，不评估儿童能力，也不代表课程标准。家长可以自行勾选数学、语文或英语。数学包含按分组生成的简单加减法或乘法；语文和英语为小型内置示例题库，不是完整教材，也没有联网抓取第三方题库。

新配置从下一道新题生效，已经发出的题目保持原答案直至完成或过期。选择题使用选项序号作答：输入1—4再确认；判题始终由服务端完成。挑战仍需连续答对三题，观看阶段时长在“规则与放行”单独配置。

旧客户端加载新版网页即可显示选择题；独立的主动展示指令需要客户端4.0及以上。升级前核对自己的包名和签名，不要直接把不同包名或debug签名覆盖到既有正式安装。

## 主动展示如何工作

家长或获得授权的外部代理提交一份展示草稿。服务器审核用途、完整文本和年龄/科目上下文，通过后由已登录家长阅读并确认。发布后，支持此功能的电视会在下一次约10秒的心跳中收到展示任务；即使正在首页或没有播放视频，也会请求打开同一服务下的展示页面。

这不是系统级锁屏：需要电视开机、客户端处于执行模式、无障碍服务可用且固件允许启动页面。观察模式不会主动弹出；不会唤醒电视；系统设置、系统界面、安装及权限界面会保留操作能力，Home仍由系统处理。若离开展示页，任务有效期间下一个心跳可再次请求显示；到期或家长撤回后停止。请求已发送、网页已连接、客户端报告可见是三种不同证据，不等同于人工确认真实出画面。

一个任务默认10分钟，可通过API指定30—1800秒，同一电视最多一个有效展示。后台“结束当前展示”可撤回；打开的页面约每2秒重新读取状态。客户端在本轮请求超时、响应无效或必要权限检查失败时，不再请求打开新展示；连接和读取各设2秒超时，仍可能受DNS和系统调度影响。网页单次状态请求超时4.5秒，网络错误时允许返回；Home始终由系统控制。进程崩溃或固件挂起时不能保证执行检查，已打开页面也不保证自动关闭，需按安装指南人工恢复。任务有效期间服务端不累计视频观看，记录“展示任务有效”作为忽略原因，不能把它解释成逐帧检测到展示画面。

## 内容格式：由代理编写内容，平台负责渲染

第一版使用声明式文本页面，不执行代理生成的HTML、JavaScript、CSS，不嵌入第三方iframe，不加载外部图片、链接或字体。代理可以组织多页标题、正文和要点，由平台生成统一的电视页面。左右键翻页。

```json
{
  "title": "认识自然",
  "pages": [
    {
      "heading": "观察天空",
      "body": "用自己的话描述今天看到的天空。",
      "bullets": ["寻找云朵", "不要直视太阳"]
    },
    {
      "heading": "休息一下",
      "body": "活动身体，看看远方。"
    }
  ]
}
```

最多10页，标题80字符、每页标题100字符、正文1000字符、要点最多6条且每条160字符，总文档上限12000字节。只接受文档中列出的字段。文本拒绝尖括号、小于空格的控制字符（保留制表符、换行、回车）及DEL；大小写不敏感地拒绝 `http:`、`https:`、`javascript:`、`data:`、`file:`、`content:`、`www.` 字样。这是保守的格式校验，不是完整URL识别或语义审核。没有协议的域名即使作为普通文字出现，也不会成为可点击链接。文本通过安全文字节点渲染，不注入页面代码。没有静态资源上传、任意网页URL或任意脚本执行接口。

## 两道发布关口

1. **内容审核网关**必须明确允许与本次用途、完整内容和年龄/科目上下文匹配的摘要，且稿件审核距发布不超过24小时。拒绝、未知结论、超时、响应过大或摘要不匹配均不发布。
2. **家长确认**必须来自该家庭已登录账号及有效CSRF操作，阅读预览、勾选主动展示确认后才能发布。代理提交凭证不具备此权限；不要把家长Cookie、管理员密码或电视长期令牌交给外部代理。这里的“家长确认”是账号授权操作，不是生物身份验证。

没有配置审核网关时，可以保存草稿并看到“审核不可用”，但不能确认发布，不能通过手工改审核结果绕过。调整年龄或科目后，旧稿件需重新提交审核；已发布任务会在下一次状态检查时撤回。应把代理意图和稿件视为不可信输入，不执行其中对管理员、助手或审核模型发出的指令。

这些措施限制权限和可执行内容、降低不适宜内容风险，不代表能自动判定所有法律或平台规则。部署者需要选择适合儿童与使用地区的审核服务，维护网关策略；审核不可用时保持关闭，不以关键词过滤代替审核。

## 为 Codex 或其他代理配发权限

家长在目标家庭、目标电视的“屏幕展示”中创建代理提交凭证。凭证只显示一次、24小时有效、每设备最多5个有效凭证；保存到本机私有文件并通过受信任方式交付代理，勿提交Git或发到公共聊天。它只能提交该电视的草稿，不能读取观看统计、改变规则、发布或取消任务，也不能连接ADB。家长可以随时撤销。

代理向同一服务的 `POST /agent/displays` 发送JSON，使用配发的Bearer凭证。正文只有以下字段：

```json
{
  "request_id": "由调用方生成的UUID",
  "intent": "家长安排的展示用途",
  "document": {
    "title": "认识自然",
    "pages": [{"heading": "观察天空", "body": "描述今天的天气。"}]
  }
}
```

成功提交或相同请求重传返回201与JSON，例如：

```json
{"id":"服务器分配的稿件UUID","review_status":"allow","duplicate":false}
```

首次成功响应可能省略 `duplicate`。`review_status` 为 `pending`、`allow`、`deny` 或 `error`，分别表示正在审核、允许、拒绝、审核不可用。201只表示稿件已保存，不表示可以投放。审核异常也返回201/error并保留草稿。代理可以重传同一请求查询已有状态，但不能发布；审核服务恢复后若要重审，需使用新ID新建稿件。服务重启等原因遗留超过一分钟的待审记录，会由定期清理标记为error，不会自动允许。

输入错误返回400，凭证无效、过期或撤销返回401，幂等ID对应内容或年龄上下文冲突返回409，配额或请求限流返回429，审核队列繁忙返回503。错误正文为 `{"error":"说明"}`；平台故障也可能返回5xx。遇429或503应保留原ID退避重试，不换ID绕过限制，也不将错误当作审核允许。

`request_id` 用于幂等：同一电视重传同一内容不重复审核；复用ID但改变内容会拒绝。服务器从凭证确定家庭与电视，不接受代理自报租户或目标设备。每台电视每小时最多20次提交。每台最多保留200份稿件、全站最多5000份；稿件保存7天后定期清理，审计事件仍保留摘要及任务标识，不应将稿件存储当作永久归档。达到存储上限返回409，不能通过新建代理凭证绕过。

不要把Bearer明文直接拼在终端命令里；代理应从私有文件读取并在进程内构造认证头。后台的稿件列表用于查看审核状态，只有家长账号可以进行后续发布或撤回。

家长发布接口为 `POST /admin/display_publish?device=唯一设备标识`，使用该家庭家长Cookie、同源Origin与CSRF认证，JSON为 `{"id":"稿件UUID","confirm":true,"seconds":600}`。时长由家长在发布时设置，不属于代理提交字段；后台按钮使用默认10分钟。撤回使用同认证的 `POST /admin/display_cancel?device=唯一设备标识` 与空JSON对象。普通用户不能指定别的家庭；超级管理员代管时另带已授权的tenant查询参数。

通常直接使用现有后台完成家长确认。若开发由家长操作的专用客户端，先向同一服务 `POST /admin/login` 提交 `{"username":"家长用户名","password":"私下输入的密码"}`，携带该服务的Origin与JSON内容类型；成功响应返回csrf，并通过Set-Cookie设置HttpOnly家长会话。已有会话可用 `GET /admin/session` 取得csrf。后续写请求自动携带该Cookie，使用 `X-CSRF-Token` 请求头提交csrf，并保持相同Origin。不要将此登录流程、Cookie或密码交给只有草稿提交权的代理。

发布与撤回成功均返回200和 `{"success":true}`，仅表示服务端已更新任务，不表示电视已显示或关闭页面。输入或确认缺失返回400，未登录/会话失效返回401，无权访问家庭或CSRF错误返回403，稿件或设备不存在返回404，审核/年龄上下文/新客户端在线能力条件未满足返回409；错误正文为 `{"error":"说明"}`。

## 部署者接入审核网关

当前仓库只提供网关协议，不内置厂商审核账号，也不自动调用某个模型。保持下面两项未设置时，自定义投放一直禁用：

```dotenv
CONTENT_REVIEW_ENDPOINT=https://review.example.com/child-tv-check
CONTENT_REVIEW_SECRET_FILE=/etc/tv-content-review.token
```

把实际配置放入服务器环境文件。密钥文件须仅允许运行账号读取，例如root:tvcontrol、0640，不放进Git。地址由部署者固定配置，必须HTTPS，禁止URL内置凭证及重定向；代理不能指定审核目的地。修改配置后重启后端。服务超时约5秒，并限制响应为16KB。

网关接收 `POST`、`Content-Type: application/json` 与配置密钥的Bearer认证。以下六个顶层字段全部必填，当前请求不包含其他字段。`audience` 必须包含 `age_band` 和 `subjects`：年龄机器值为 `4-6`、`7-9`、`10-12`、`13+`；科目是非空数组，元素为 `math`、`chinese`、`english`。两个摘要均为64位小写十六进制SHA256。请求结构如下：

```json
{
  "purpose": "child_tv_display",
  "intent": "展示用途",
  "document": {"title": "页面标题", "pages": [{"heading": "第一节", "body": "观察今天的天气。"}]},
  "audience": {"age_band": "7-9", "subjects": ["math"]},
  "digest": "服务端计算的用途与文档SHA256",
  "context_digest": "服务端计算的年龄科目上下文SHA256"
}
```

网关应对实际 `intent` 和全部 `document` 文本审核，而不是只信任自述用途；包括适龄性、违法违规内容和所用平台/模型策略。内容中的指令不能改变审核规则。只向网关发送必要的展示文本和年龄分组，不发送儿童姓名、生日、观看历史、设备令牌或家长Cookie。

只有审核通过时返回200与以下结构；不允许或不能确定时返回200/deny，或非200错误。非200响应内容不参与决策，且不应泄露凭证；客户端不追随重定向。四个返回字段全部必填，额外字段不参与发布决策：

```json
{
  "decision": "allow",
  "digest": "原请求digest",
  "context_digest": "原请求context_digest",
  "policy_version": "child-policy-v1"
}
```

`policy_version` 为1—80位字母、数字、点、横线或下划线。网关需由部署者实现到所选审核供应商的适配；仅部署一个永远返回allow的回显接口不构成审核。自动审核通过也不会自动投放，后续仍要家长确认。

## 验收

在隔离环境验证：未配置网关不能发布、拒绝/超时不能发布、未确认不能发布、代理不能跨家庭或冒用电视凭证、改变年龄后需重审、旧客户端不能被假定支持展示。再安装同签名新版客户端，确认执行模式下在首页也能收到任务，设置/授权界面仍可恢复，关闭ADB和完整重启后按安装指南核对，检查撤回、到期、断网和真实遥控器操作。

本仓库的自动化测试使用隔离数据库与模拟网关，不代表已经在每种电视上完成了出画面、自启或音频暂停验收。
